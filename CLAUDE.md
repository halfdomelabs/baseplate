## Tools

- **TypeScript LSP:** Use the `typescript-lsp` tool (via the LSP tool) to get type information, find references, go to definitions, and diagnose type errors. This is especially useful when navigating unfamiliar code or debugging complex type issues.
- **Generated templates:** Never modify generated templates under generators/.../generated/\*\* manually. Instead, use the /modify-generated-code skill to modify the generated code using the Baseplate MCP tools. If you encounter any issues with template extraction such as inability to connect to the MCP server, please report them to the team rather than working around it.
