# @baseplate-dev/project-builder-lib

The Baseplate plugin system: plugin specs, the plugin spec store, plugin metadata, and the loader that discovers and initializes plugin modules in dependency order.

The project-definition schema, compiler and web helpers from the original Baseplate were removed in the rebuild cutover. They live on the [`legacy`](https://github.com/halfdomelabs/baseplate/tree/legacy) branch.
